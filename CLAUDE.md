# Tala

Renamed from Sema on 2026-11-04: the snap name `sema` was taken. The user registered `tala` (Old Norse "to speak"). Older notes below say Sema.

Unofficial snap of the official Nextcloud Talk desktop client (nextcloud/talk-desktop). It repackages Nextcloud's unmodified Linux ZIP. There is no app code here: to change app behavior, contribute upstream.

Status is kept in this file.

## Recipe notes
- Version and ZIP sha256 are pinned in `snap/snapcraft.yaml`.
- The ZIP's top directory is mode 700, so `chmod -R a+rX app` in override-prime is required.
- The client hides its startup setting on Linux. `sema.autostart on|off|status` and the launcher right-click actions provide it.
- No NVIDIA env workaround is needed (tested on RTX 2080, Wayland, gpu-2404).
- Testing: build with `snapcraft pack`, `sudo snap install --dangerous`, then connect browser-sandbox, camera and audio-record by hand. `--remote-debugging-port=9222` exposes GPU and sandbox state over CDP.
- Build on skyfire only with at least 20G free on `/`, then `snapcraft clean`.

Join-first (built 2026-11-06, no real call yet): `Call.start` opens media alongside joining, joins with audio and video flags, rings, then publishes when the camera is ready. Late publishers are covered by the signaling server holding a stream request (`getPublisher` in `sfu/janus/janus.go`, 10s default `mcu timeout`), web retrying every 10s and iOS for 60s; Android sends one request, so it relies on the server's wait, which an 8s camera only just fits. If media fails, Tala stays in the call receive-only and corrects the flags with `PUT call/{token}`. Test with a real call both ways: the other side must get audio and video.
Call screen (the user's request, 2026-11-06): remote video fills everything under the app bar in cover mode (`FillGrid` in `call_layout.dart`), cropping rather than leaving bars, so a phone's portrait video in a wide window loses its top and bottom. Ringback: `Ringback` in `ringer.dart`, `assets/sounds/ringback.wav` from `tool/make_ringback.py`, `tala --test-ringback`. Plays only if nobody was in the call at the start, from joining until anyone else is in the call, at most 60s, once per call. Not yet heard by the user.

## Right-click actions (built 2026-11-06, user confirmed working on the real server)
Right-click a message for Reply, Copy text, Edit and Delete, or use the hover "More actions" button (keyboard route); right-click a conversation or its options button for Remove chat. Remove means `DELETE /room/{token}/participants/self`, which only affects this user. Deleting a conversation for everyone (`DELETE /room/{token}`) is deliberately not offered. Edit is for your own non-attachment messages and turns mentions back into `@"id"`; moderators can delete others' messages except in one-to-ones. The server has `delete-messages-unlimited`; the docs give edit a 24-hour limit and delete a 6-hour one, and Tala shows the server's refusal rather than hiding the option. Talk supports archiving (`archived-conversations-v2`); see Archived conversations.

## Tray and background (built 2026-11-06)
User confirmed on 2026-11-06: the close button keeps Tala in the tray.
Native, no pub packages: `linux/runner/tray.cc` uses libayatana-appindicator (build needs `libayatana-appindicator3-dev`). `tray_manager` and `window_manager` were rejected: they moved onto the young `nativeapi` in late 2026 with several releases a week, and `system_tray` was last released in April 2023. The library warns at runtime that it's deprecated for libayatana-appindicator-glib; revisit when distributions ship that widely. Closing the window hides Tala only while a tray host is connected, otherwise it quits. The app is now unique on D-Bus, so a second launch brings up the running copy; launching with any argument (developer modes) stays separate. Tray Quit hangs up an active call first (3s limit in Dart, 5s in the runner). An incoming call shows a hidden window. `lib/src/tray.dart` is the Dart side, on channel `tala/tray`. `tool/install-desktop.sh` adds a launcher for the local build (installed on skyfire).
Verified by me: `tala --tray-selftest` (closes the window through the same path as its close button, Dart keeps running while hidden, drawing resumes on show), icon registered with the watcher, menu Quit over D-Bus exits cleanly, second launch leaves one copy. Not verified: tray Open clicked by hand, how the icon looks in the top bar, a call ringing a hidden window, Quit during a call. A snap must ship the library and needs a D-Bus name for the unique app. Mac and Windows need their own tray code. "Start at login" in the app menu (moved from the tray on 2026-11-06 at the user's request; off by default) writes `~/.config/autostart/<app id>.desktop` running `tala --background`, which stays hidden, or shows the window if no tray host appears in 20s.
